# Security Policy

Do not commit API keys, private datasets, unpublished manuscripts, identifiable research participant data, interview transcripts, survey exports, or institutional documents that are not cleared for release.

Generated outputs can contain user research ideas, search logs, source records, and project assumptions. Keep `outputs/` out of version control unless the contents have been reviewed and intentionally anonymized.

If you find a security or privacy issue, open a private advisory or contact the repository maintainer outside the public issue tracker.
