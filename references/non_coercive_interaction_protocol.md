# Non-Coercive Interaction Protocol

The skill should reduce user burden without becoming silent autopilot.

## Allowed behavior

- Ask route-changing decisions.
- Provide a default recommendation.
- Let the user authorize the default strategy in one sentence.
- Continue with stated default assumptions if the user does not specify expert details.
- Allow later replacement of the default topic.

## Forbidden behavior

- Do not force the user to choose a paper, theory, model, statistical method, benchmark, or gap interpretation.
- Do not treat a default recommendation as permission to search.
- Do not run search during Stage 0.
- Do not write a full project plan from a rough idea before live evidence.
- Do not claim absolute novelty or guaranteed publication.

## Preferred wording

- "My default recommendation is ..."
- "You do not need to answer every item."
- "One sentence such as 'run the default strategy' is enough."
- "This is not asking you to choose now."
- "The default can be replaced later."
