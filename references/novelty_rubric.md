# Novelty Rubric

Novelty must be scoped to the search range. Never claim absolute novelty.

## Acceptable novelty language

- "Within the current search scope, no highly similar study was found."
- "The contribution appears to be a context-transfer, data, mechanism, validation, or measurement contribution."
- "This claim requires domain database search or citation chasing before being tightened."

## Forbidden novelty language

- "No one has studied this."
- "This is the first study."
- "This is a clear blank space."
- "This will definitely publish."
- "This is absolutely novel."

## Gap types

- Context gap: same question, different population/setting.
- Data gap: same question, stronger or more transparent data.
- Method gap: same object, better validation, baseline, robustness, or interpretability.
- Mechanism gap: same association, missing mediation/moderation or causal pathway.
- Measurement gap: same construct, better operationalization.
- Synthesis gap: scattered evidence lacks an evidence map or taxonomy.
