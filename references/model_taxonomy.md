# Model Taxonomy

Models are optional. A model is justified only when it answers the research question better than a transparent baseline.

## Baselines

- Descriptive baseline.
- Majority-class or rules-based baseline.
- Linear/logistic regression.
- Simple thematic coding baseline.
- Evidence-map baseline.

## Candidate models

- Regularized regression.
- Tree ensembles.
- Gradient boosting.
- Calibrated probabilistic model.
- Structural equation model.
- Mediation/moderation model.
- Topic model or embedding-based clustering.
- Simulation or scenario model.

## Evaluation

Match metrics to the research purpose: accuracy, F1, AUROC, calibration, effect size, reliability, validity, coding agreement, sensitivity analysis, subgroup error, decision utility, or interpretability.
