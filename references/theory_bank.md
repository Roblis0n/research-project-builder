# Theory Bank

Use theory only when it changes measurement, data collection, modeling, mechanism explanation, or interpretation.

## Common theory families

- Social cognitive theory: useful for self-efficacy, capability, anxiety, behavior change, and performance mechanisms.
- Technology acceptance / affordance theory: useful for tool adoption, perceived usefulness, human-tool interaction, and affordance mechanisms.
- Cognitive load theory: useful when task difficulty, attention, or learning burden matters.
- Academic identity theory: useful for research training, scholarly identity, and professional formation.
- Institutional theory: useful for organizations, policy pressure, legitimacy, and compliance.
- Stakeholder theory: useful for governance, disclosure, ESG, accountability, and external pressure.
- Gap taxonomy / evidence synthesis framing: useful when the correct output is a map of existing evidence and executable next steps.

## Selection rule

Do not choose theory by name recognition. Choose it only if it changes variables, constructs, data, method, mechanism, or interpretation.
