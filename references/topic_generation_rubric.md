# Topic Generation Rubric

Executable topic candidates must be evidence-backed, data-aware, and downgradeable.

## Required fields

Each topic must include:

- title;
- one-sentence explanation;
- research object;
- unit of analysis;
- existing literature basis;
- difference from existing work;
- core gap;
- minimum data requirement;
- data acquisition route;
- minimum method requirement;
- optional advanced method;
- tool stack;
- expected output;
- first-week action;
- failure condition;
- risk;
- fallback option;
- later theory/method/model expansion direction.

## Quality criteria

A strong topic answers:

- what to do;
- why it is worth doing;
- where existing research has reached;
- where the project can still enter;
- what data to use;
- what method to use;
- what to do first;
- how to downgrade if blocked.

Do not rank topics by ambition alone. Prefer the topic that balances feasibility, evidence-supported gap, data availability, method fit, and risk control.
