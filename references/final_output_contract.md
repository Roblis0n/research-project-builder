# Final Output Contract

The user-facing output must be complete inside the Codex conversation. Generated files are audit artifacts, not the primary answer.

## Stage 0 output must include

- Strategic Decision Gate.
- D1-D7 decisions.
- Default recommendation.
- Choice consequence.
- Risk judgment.
- Data reality judgment.
- Method complexity judgment.
- Time-window judgment.
- Next execution action.
- A clear stop before search unless authorized.

## Stage 1 output must include

- Live search scope.
- Closest existing research.
- Coverage judgment.
- Executable topic candidates.
- Default recommendation.
- Default execution route.
- Strategic decision state.
- Strategic decision questions.
- Later expansion options.

Each topic must include research object, unit of analysis, existing literature basis, difference from existing work, core gap, minimum data, data acquisition route, minimum method, optional advanced method, tool stack, expected output, first-week action, failure condition, risk, fallback option, and later expansion direction.

## Stage 2 output must include

- Selected Topic.
- Theory Candidate Table.
- Recommended Main Theory.
- Why Not the Other Theories.
- Conceptual Model.
- Constructs / Variables.
- Hypotheses or Propositions.
- Data Plan.
- Method Route.
- Statistical / Machine Learning / Simulation Model.
- Baseline.
- Candidate models.
- Evaluation metrics.
- Robustness checks.
- Tool Stack.
- MVP.
- 12-Week Execution Plan.
- Risks and Fallbacks.
- Writing Structure.

## Forbidden final-output behavior

- Do not tell the user to open a file to understand the result.
- Do not claim absolute novelty.
- Do not claim guaranteed publication.
- Do not force the user to choose.
- Do not hide missing live evidence.
