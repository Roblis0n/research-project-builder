# Stage 1 mock output

This file illustrates the expected shape of a topic-landing result. It is not a claim about actual literature.

## Search scope

- Structured sources: OpenAlex, Semantic Scholar, Crossref.
- Live source log: `live_web_sources.json`.
- Evidence matrix: `evidence_matrix.csv`.

## Executable topic candidates

A valid Stage 1 output should include 3-5 candidate topics. Each candidate should specify title, research object, unit of analysis, literature basis, difference from existing work, core gap, minimum data, data acquisition, minimum method, optional advanced method, tool stack, expected output, first-week action, failure condition, risk, fallback option, and later expansion direction.

## Default recommendation

A valid Stage 1 output should include one default topic and should explicitly state that the user does not need to choose immediately.
