# Stage 2 mock output

This file illustrates the expected shape of a theory/method/model expansion. It is not a substitute for running the scripts.

A valid Stage 2 output should include:

- selected topic;
- theory candidate table;
- recommended primary theory;
- conceptual model;
- constructs and variables;
- hypotheses or propositions;
- data plan;
- method route;
- baseline;
- candidate models;
- evaluation metrics;
- robustness checks;
- tool stack;
- MVP;
- 12-week execution plan;
- risks and fallback routes;
- writing structure.
